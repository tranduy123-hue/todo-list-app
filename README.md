# To-Do List App

Một ứng dụng To-Do List đơn giản bằng Python phục vụ học phần **Nhập môn Công nghệ phần mềm**.

## Tính năng
- **Thêm công việc (`add_task`)**: Thêm công việc mới vào danh sách.
- **Liệt kê công việc (`list_tasks`)**: Hiển thị danh sách công việc có đánh số thứ tự kèm trạng thái hoàn thành (`[ ]` hoặc `[x]`).
- **Đánh dấu hoàn thành (`complete_task`)**: Đánh dấu một công việc là đã hoàn thành theo chỉ số.
- **Xóa công việc (`delete_task`)**: Xóa một công việc khỏi danh sách theo chỉ số (có kiểm tra chỉ số hợp lệ).

## Hướng dẫn chạy chương trình
Chạy file `app.py` bằng Python:
```bash
python app.py
```
